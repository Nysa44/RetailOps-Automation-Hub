# Power Platform implementation assets

These files are implementation blueprints, not a deployed or connected Power Platform solution.

- `dataverse-schema.md`: suggested Dataverse tables, columns, relationships and alternate keys.
- `cloud-flow-spec.md`: low-stock replenishment, approval and exception routing flow designs.
- `powerfx-examples.txt`: sample Canvas App formulas.
- `custom-connector-openapi.yaml`: starter OpenAPI 3.0 definition for the demo API. Update the server URL and configure authentication before importing.
